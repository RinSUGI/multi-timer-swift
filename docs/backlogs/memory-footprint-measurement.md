# メモリ実測・合否確定

## 背景

NFR-01（[10-requirements/non-functional.md](../design-docs/10-requirements/non-functional.md)）はアイドル常駐時のメモリの目標を 10〜30MB としているが、合否の閾値は実装前には確定できないため、実測後に判断することとした（同ファイル OQ-02）。

## 現状

実装済み。`.app` の生成も確認済み。メモリ実測は未実施。

## 対応方針

1. アイドル常駐状態（タイマー 1 個表示・非実行）で次のいずれかを使って実測する。
   - アクティビティモニタの「メモリ」列
   - `footprint <PID>` コマンド
   - `vmmap <PID>` コマンド
2. 合否判定（NFR-01 の決定に基づく）:
   - 30MB 以下 → 合格確定。`progress-list.json` の `NF-1` ステータスを `completed` に更新する。
   - 30MB 超 → 原因調査。ヒープ・フレームワーク保持量を `vmmap` で確認し、削減策を検討する。

## 受け入れ条件

- 実測値を記録する。
- 30MB 以下であれば本バックログを完了とし、超えていれば削減対応の Issue を別途起票する。
