# ウィンドウを閉じても計時を継続して通知（OQ-11）

## 背景

既存 Electron 版では、ウィンドウを閉じた状態でもタイマーのカウントダウンが継続し、終了時に通知が届く。Swift 版でも同等の挙動が望ましい改善として議論された（OQ-11）。

## 現状

Swift 版ではウィンドウを閉じると計時が止まる。タイマーの状態は保持されており、ウィンドウを再表示すれば設定時間・非実行・白の状態で復元される（[BB-10](../design-docs/60-testing/blackbox-test-cases.md) 参照）。

## 対応方針

本プロジェクトの対象範囲は「既存機能の同等再現」であり、機能拡張は行わない（[purpose-and-scope.md](../design-docs/00-overview/purpose-and-scope.md)）。ウィンドウ非表示時の計時継続はバックグラウンド処理の追加を伴うため、本プロジェクトでは対応しない。将来の機能改善として記録する。

## 受け入れ条件

将来対応時に別途 Issue を起票し、実装・テストを行う。本バックログはその起点とする。
