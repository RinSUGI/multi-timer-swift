# ウィンドウを閉じても計時を継続して通知

## 背景

現状はウィンドウを閉じると計時が止まる。閉じた状態でもタイマーを走らせ、終了時に通知が届く挙動が望ましいという議論があった（[layout-and-style.md](../design-docs/50-ui/layout-and-style.md) の OQ-11）。

## 現状

ウィンドウを閉じると計時は止まる。タイマーの状態は保存済みタイトル・設定時間から復元されるため、ウィンドウを再表示すれば設定時間・非実行・白の状態で戻る（[BB-10](../design-docs/60-testing/blackbox-test-cases.md) 参照）。

## 対応方針

ウィンドウ非表示時の計時継続はバックグラウンド処理の追加を伴うため、本プロジェクトでは対応しない。将来の機能改善として記録する。

## 受け入れ条件

将来対応時に別途 Issue を起票し、実装・テストを行う。本バックログはその起点とする。
