# 時間切れ後の黄色表示ルール

## この文書で決めること

カウントダウンが自然終了した後に数字を黄色で表示する条件を定義する。

## 目的

表示が設定時刻のままになっているとき、それが「まだ開始していない」のか「既に時間切れで自動リセットされた」のかを、色で区別できるようにする。

- 白: まだ開始していない、またはカウントダウン中。
- 黄色: カウントダウンが自然に終わって自動リセットされた状態。

## 黄色にする条件

- `expiredAfterCountdown = true` のときのみ数字を黄色で表示する。
- このフラグが `true` になるのは、実行中のカウントダウンが `remainingMs <= 0` に到達した瞬間だけである（[timer-behavior.md](timer-behavior.md) の自動リセットを参照）。

## 白に戻す（黄色を解除する）条件

`expiredAfterCountdown` を `false` にするのは次の場合。

- Start したとき（カウントダウン中は白）。
- Clear したとき。
- セグメント編集を確定したとき（設定時間を変更したとき）。
- 起動直後（永続化しないため、常に `false` から始まる）。

## 黄色を維持する / 変化させない場合

- 手動 Reset では `expiredAfterCountdown` を変更しない。ただし自然終了直後は Reset ボタンが非活性のため、実際に「黄色のまま Reset」に至る操作経路は通常存在しない。
- Stop では変更しない（そもそもカウントダウン中は `false`）。

## 再スタート時の遷移

黄色状態から同じタイマーを再度 Start した場合。

1. Start により `expiredAfterCountdown = false` → カウントダウン中は白。
1. 再び 0 に到達すると `expiredAfterCountdown = true` → また黄色。

## 永続化しない

- 黄色状態はそのセッション内のみ保持する。DB に保存しない。
- 再起動時は白に戻る。

## 状態と文字色の対応表

| 状態                               | 文字色         |
| ---------------------------------- | -------------- |
| 起動直後                           | 白             |
| カウントダウン中                   | 白             |
| カウントダウン完了後の自動リセット | 黄色           |
| 手動リセット                       | 白（変化なし） |
| 黄色から再スタートしカウント中     | 白             |
| 黄色から再スタートし再び完了       | 黄色           |
| 設定時刻を編集                     | 白             |
| クリア                             | 白             |

## 配色

- 黄色の具体値は [50-ui/layout-and-style.md](../50-ui/layout-and-style.md) の配色表（`#ffd60a`）を参照。
