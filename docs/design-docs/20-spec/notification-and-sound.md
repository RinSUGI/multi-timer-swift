# 通知とチャイム音の仕様

## この文書で決めること

カウントダウン終了時のチャイム音と macOS 通知の仕様、および初回再生の遅延対策を定義する。

## 終了時の一連の動作

タイマーが 0 に到達したとき、次を行う。

1. チャイム音を再生する。
1. そのタイマーのタイトルを添えて macOS 通知を表示する。

これらはタイマーごとに独立して発生する。

## macOS 通知

- タイトル: タイトルが空でなければ `<タイトル> 終了`、空なら `タイマー終了`。前後の空白は除去して判定する。
- 本文: `設定した時間が経過しました`。
- 複数のタイマーが相前後して終わった場合、1 つにまとめず、終わった順にスタック表示する。
  - 実装方針: `UserNotifications`（`UNUserNotificationCenter`）を用い、通知ごとに一意の識別子を与えて OS 側でまとめられないようにする。
- 通知が OS 側で無効・非対応の場合は、音のみで静かに継続し、エラーにしない。

### 通知許可

- 初回起動時に通知の許可を要求する（`UNUserNotificationCenter` の `requestAuthorization`）。
- 許可されていない場合でもアプリは正常に動作し、音は鳴る。
- 利用者向けの許可手順は配布時のインストール手順（`docs/インストール手順.md`）に含める。

## チャイム音

- 「おぜ」を模した 2 音のチャイム（ヘ長調）。
  - 1 音目「お」= E: C メジャー和音（C4-E4-G4）+ メロディ E5。長さ約 0.45 秒。
  - 2 音目「ぜ」= D: B♭ メジャー和音（B♭3-D4-F4）+ メロディ D5。長さ約 0.90 秒。
- 音色: 基音に倍音（2 倍・3 倍）を重ねてピアノ風にする。倍音比は基音 0.07 / 2 倍 0.02 / 3 倍 0.007。各音は立ち上がり後にゆるやかに減衰させる。

### 具体的な周波数

| 音      | 和音とメロディ（Hz）              | 長さ（秒） |
| ------- | --------------------------------- | ---------- |
| お（E） | 261.63 / 329.63 / 392.00 / 659.25 | 0.45       |
| ぜ（D） | 233.08 / 293.66 / 349.23 / 587.33 | 0.90       |

### 実装方針

- 上記の 2 音をあらかじめオーディオファイル（`.caf`）にレンダリングしてバンドルし、`AVAudioPlayer` で再生する。
- 実装が単純で、初回再生の遅延を抑えやすい。生成の詳細は [40-architecture/technology-choices.md](../40-architecture/technology-choices.md) を参照。

## 初回再生の遅延対策（重要）

`AVAudioPlayer` / `AVAudioEngine` の初回利用時、OS のオーディオデバイスの起動に時間がかかり、終了パス上で数百 ms〜1 秒ほどメインスレッドがブロックされる場合がある。カウントダウン最終秒の見え方が伸びる原因になるため、次の対策を採る。

- 音声サブシステムを、カウントダウン終了パス上ではなく、事前に一度だけ暖機（ウォームアップ）しておく。
- 具体的には、アプリ起動直後の早い段階、あるいは「ウィンドウ上での最初のクリック / キー入力」で 1 回だけプレイヤーを初期化する。タイマーの設定・開始には必ずクリックかキー操作が伴うため、どのタイマーも 0 到達より前に暖機が済む。

関連する非機能要件は [10-requirements/non-functional.md](../10-requirements/non-functional.md) の NFR-03 を参照。
