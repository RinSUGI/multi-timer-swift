# 時刻セグメント編集の仕様

## この文書で決めること

時刻表示 `HH:MM:SS` の各セグメントを直接編集して設定時間を決める操作の仕様を定義する。

一次情報源: `_archive/multi-timer-mac/src/renderer/timer.ts`（`startEditing` / `finishEditing` / `applySegmentEdit` / `clampSegmentValue`）。

## 編集の開始

- 編集は非実行中のみ可能。実行中はセグメントを編集できない。
- セグメントをクリックすると、その桁が入力欄に変わる。
- キーボードでセグメントにフォーカスし、`Enter` または `Space` を押しても編集を開始できる。
- 既に別のセグメントを編集中に新しいセグメントの編集を始めた場合、直前の編集は確定してから移る。
- 入力欄は初期状態でその桁の現在値（2 桁ゼロ埋め）を表示し、全選択状態にする。

## 入力の制約

- 数字のみ受け付ける。非数字は入力時に除去する。
- 最大 2 桁。
- 確定時に範囲へクランプする。

| セグメント    | 範囲  |
| ------------- | ----- |
| 時（hours）   | 0〜99 |
| 分（minutes） | 0〜59 |
| 秒（seconds） | 0〜59 |

- クランプの規則: 入力から非数字を除いて整数化し、数値でなければ 0、範囲外は下限 0・上限（各セグメントの最大値）に丸める。

## キー操作

| キー        | 動作                                                                                 |
| ----------- | ------------------------------------------------------------------------------------ |
| `Enter`     | 入力を確定して編集を終える                                                           |
| `Escape`    | 編集をキャンセルし、値を元に戻す                                                     |
| `Tab`       | 現在の入力を確定し、次のセグメントの編集へ移る。末尾（秒）からは先頭（時）へ巡回する |
| `Shift+Tab` | 現在の入力を確定し、前のセグメントの編集へ移る。先頭（時）からは末尾（秒）へ巡回する |
| `→`         | 現在の入力を確定し、右のセグメントへ移る。末尾では移動しない（巡回しない）           |
| `←`         | 現在の入力を確定し、左のセグメントへ移る。先頭では移動しない（巡回しない）           |

- セグメントの外をクリックする（フォーカスを外す）と、入力は確定される。

`Tab` と矢印キーの巡回挙動の違いに注意する。

- `Tab` / `Shift+Tab`: 端で反対側へ巡回する。
- `←` / `→`: 端では移動しない。

## 確定時の状態変化

編集を確定（`applySegmentEdit` 相当）したとき、次を行う。

1. 現在の残り時間から時・分・秒を取り出し、編集したセグメントだけをクランプ後の値で置き換える。
1. 3 桁を合成して新しいミリ秒値を得る。
1. `remainingMs` と `configuredMs` の両方をその値にする（編集は設定時間そのものを決める操作である）。
1. `expiredAfterCountdown = false` にする（黄色を解除する。[expired-coloring.md](expired-coloring.md) を参照）。
1. 永続化する（即時保存。タイトルはデバウンス、確定は即時。[30-data/persistence.md](../30-data/persistence.md) を参照）。

## キャンセル時の挙動

- `Escape` による編集キャンセルは、入力値を適用せず、その桁を編集前の表示に戻す。
- Reset 操作中に編集中セグメントがあった場合も、編集は破棄される（[timer-behavior.md](timer-behavior.md) の Reset を参照）。

## 時刻とミリ秒の相互変換

表示とミリ秒の変換は次の規則で行う（純粋関数として切り出し、単体テスト対象とする。[60-testing/unit-test-design.md](../60-testing/unit-test-design.md) を参照）。

- ミリ秒 → 時分秒: 総秒数は `ceil(ms / 1000)` を 0 で下限クランプ。時 = 総秒 / 3600、分 = (総秒 % 3600) / 60、秒 = 総秒 % 60。
- 時分秒 → ミリ秒: `(時 * 3600 + 分 * 60 + 秒) * 1000`。
- 表示整形: 各値を 2 桁ゼロ埋め。

`ceil` を使う点に注意する。残り 500ms でも表示上は「01」秒と切り上げる。カウントダウンが最後に「01」から「00」へ変わる見え方はこの規則に依存する。
