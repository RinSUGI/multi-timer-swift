# 機能要件

## この文書で決めること

本アプリが満たすべき機能を一覧化する。各機能の詳細な振る舞いは [20-spec/](../20-spec/) 配下の仕様書が正本であり、本書はリンクで参照する。

## 機能一覧

### F-01 複数タイマーの並列管理

- タイマーを縦に並べて複数保持できる。各タイマーは独立してカウントダウン・通知する。
- 上限は 12 個。上限に達すると追加操作を無効化する。
- 詳細: [20-spec/multi-timer.md](../20-spec/multi-timer.md)

### F-02 時・分・秒の直接編集

- 時刻表示の各セグメントをクリックまたはキーボードフォーカスして数値を入力し、設定時間を決める。
- 範囲: 時 0〜99、分 0〜59、秒 0〜59。
- 詳細: [20-spec/time-editing.md](../20-spec/time-editing.md)

### F-03 タイトル設定

- タイマーに任意のタイトル（最大 50 文字）を付けられる。
- タイトルは終了通知にも表示される。
- 詳細: [20-spec/timer-behavior.md](../20-spec/timer-behavior.md)、永続化は [30-data/persistence.md](../30-data/persistence.md)

### F-04 開始 / 停止 / リセット / クリア

- 各タイマーに 4 つのボタン（Start / Stop / Reset / Clear）で操作する。
- ボタンの活性・非活性は状態に応じて切り替わる。
- 詳細: [20-spec/timer-behavior.md](../20-spec/timer-behavior.md)

### F-05 終了時の通知とサウンド

- カウントダウンが 0 になるとチャイム音を鳴らし、macOS の通知を表示する。
- 複数のタイマーが相前後して終わった場合、まとめず終わった順にスタック表示する。
- 詳細: [20-spec/notification-and-sound.md](../20-spec/notification-and-sound.md)

### F-06 時間切れ後の黄色表示

- カウントダウンが自然に 0 になり自動リセットされた場合、数字を黄色で表示する。
- 起動直後・手動リセット後・クリア後・編集後は白のままとする。
- 黄色状態はセッション内のみ保持し、再起動で白に戻る。
- 詳細: [20-spec/expired-coloring.md](../20-spec/expired-coloring.md)

### F-07 状態の永続化

- 各タイマーのタイトルと設定時間を保存し、再起動時に復元する。
- 残り時間・実行中フラグ・黄色状態は永続化しない。
- 詳細: [30-data/persistence.md](../30-data/persistence.md)

### F-08 タイマーの追加

- 最下部の追加パーツ（敷居線とプラスマーク）をクリックまたはフォーカス操作すると、`新規タイマーN` の名前で末尾に追加する。
- 追加時点で DB に保存する。
- 詳細: [20-spec/multi-timer.md](../20-spec/multi-timer.md)

### F-09 タイマーの削除

- タイトル右端の赤い「×」ボタンで、そのタイマーを DB から物理削除し画面からも取り除く。
- すべて削除した状態で再起動すると、未指定の空タイマーが 1 つだけ表示される。
- 詳細: [20-spec/multi-timer.md](../20-spec/multi-timer.md)

### F-10 レスポンシブなウィンドウ

- ウィンドウをドラッグでリサイズでき、UI 全体がサイズに連動して縮小する。
- 最小幅 120px、最小高さ 100px。
- タイマーが収まらない場合は縦スクロールする。
- 詳細: [50-ui/layout-and-style.md](../50-ui/layout-and-style.md)

### F-11 ウィンドウのドラッグ移動

- タイトルバーを隠したフレームレス風ウィンドウを、背景領域のドラッグで移動できる。
- 入力欄・ボタン・時刻表示などの操作領域はドラッグ対象外とする。
- 詳細: [50-ui/layout-and-style.md](../50-ui/layout-and-style.md)

### F-12 バージョン表示

- ウィンドウ下部にアプリバージョンを `v<version>` 形式で表示する。
