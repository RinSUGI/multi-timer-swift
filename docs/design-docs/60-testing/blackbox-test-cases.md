# ブラックボックステストケース

## この文書で決めること

UI・通知・音・ウィンドウ挙動を含む、アプリ全体の手動テストケースを定義する。各ケースは「手順 → 期待結果」で書く。判定基準は仕様書（[20-spec/](../20-spec/) 配下）である。

実行は配布形式に近い `.app` で行う（通知・音など、開発実行と本番で差が出る要素があるため。[70-packaging/build-and-distribution.md](../70-packaging/build-and-distribution.md) を参照）。

## BB-01 起動と初期表示

| #   | 手順                       | 期待結果                                                  |
| --- | -------------------------- | --------------------------------------------------------- |
| 1   | 保存データが無い状態で起動 | 空タイマー（タイトル空・`00:00:00`・白）が 1 つ表示される |
| 2   | ウィンドウ下部を確認       | `v<version>` が表示される                                 |
| 3   | 上端を確認                 | 信号機ボタンにコンテンツが重ならない                      |

## BB-02 時刻の設定（セグメント編集）

| #   | 手順                                        | 期待結果                                           |
| --- | ------------------------------------------- | -------------------------------------------------- |
| 1   | 分セグメントをクリックし "5" を入力し Enter | `00:05:00` になり白のまま                          |
| 2   | 時セグメントに 3 桁目を入力しようとする     | 3 桁目は入力欄に反映されない（2 桁で打ち切られる） |
| 3   | 分に "60" を入力し Enter                    | 59 にクランプされる                                |
| 4   | 分に "1a2" のように英字混じりを入力         | 英字は除去され、`12` として扱われる                |
| 5   | セグメント編集中に Escape                   | 値が元に戻る                                       |
| 6   | セグメント編集中に Tab / Shift+Tab          | 次 / 前の桁へ移り、端で巡回する                    |
| 7   | セグメント編集中に ← / →                    | 隣の桁へ移り、端では移動しない                     |
| 8   | セグメント編集中に外側をクリック            | 入力が確定する                                     |

## BB-03 基本操作

| #   | 手順                      | 期待結果                                                                 |
| --- | ------------------------- | ------------------------------------------------------------------------ |
| 1   | `00:00:03` を設定し Start | カウントダウンが始まり、数字は白、セグメントは編集不可                   |
| 2   | 実行中に Stop             | 一時停止し、残り時間を保持                                               |
| 3   | 停止から再度 Start        | 続きから進む                                                             |
| 4   | 実行中に Reset            | 停止し、設定時間に戻る（白のまま）                                       |
| 5   | 実行中に Clear            | 停止し `00:00:00`・白                                                    |
| 6   | 各状態でボタンの活性      | [20-spec/timer-behavior.md](../20-spec/timer-behavior.md) の活性表どおり |

## BB-04 終了と黄色表示

| #   | 手順                                    | 期待結果                                                      |
| --- | --------------------------------------- | ------------------------------------------------------------- |
| 1   | `00:00:02` を設定し Start、終了まで待つ | チャイム音が鳴り、macOS 通知が出る                            |
| 2   | 終了直後の表示                          | 設定時間に自動リセットされ、数字が黄色                        |
| 3   | 通知のタイトル                          | タイトルありなら「<タイトル> 終了」、無しなら「タイマー終了」 |
| 4   | 黄色状態から再度 Start                  | カウント中は白、終了で再び黄色                                |
| 5   | 黄色状態でセグメント編集                | 白に戻る                                                      |
| 6   | 黄色状態で Clear                        | 白・`00:00:00`                                                |
| 7   | 途中で Stop → Reset                     | 白のまま（黄色にならない）                                    |

## BB-05 初回終了時の遅延（回帰確認）

| #   | 手順                                                               | 期待結果                                        |
| --- | ------------------------------------------------------------------ | ----------------------------------------------- |
| 1   | アプリを起動して最初のタイマーを `00:00:03` で走らせ、終了まで観察 | 最後の 1 秒が長く感じない（`01` → `00` が等速） |
| 2   | 2 回目以降も観察                                                   | 同様に等速                                      |

## BB-06 複数タイマー

| #   | 手順                                       | 期待結果                                                    |
| --- | ------------------------------------------ | ----------------------------------------------------------- |
| 1   | 追加パーツをクリック                       | `新規タイマーN` が末尾に追加される                          |
| 2   | 追加を繰り返す                             | N が連番で増える                                            |
| 3   | 12 個まで追加                              | 12 個で追加パーツが無効化される                             |
| 4   | タイマー A(1 秒)・B(2 秒) を同時に走らせる | A・B それぞれで音と通知が出て、まとめられず順にスタック表示 |
| 5   | ウィンドウを縮めて多数のタイマー           | 縦スクロールできる                                          |

## BB-07 削除

| #   | 手順                        | 期待結果                           |
| --- | --------------------------- | ---------------------------------- |
| 1   | タイトル右の「×」をクリック | そのタイマーが画面と DB から消える |
| 2   | すべて削除                  | 空配列が残る                       |
| 3   | すべて削除後に再起動        | 空タイマーが 1 つ表示される        |

## BB-08 永続化

| #   | 手順                         | 期待結果                                                       |
| --- | ---------------------------- | -------------------------------------------------------------- |
| 1   | タイトルと時刻を設定し再起動 | タイトルと設定時間が復元される                                 |
| 2   | 実行中に再起動               | 残り時間・実行中・黄色は復元されず、設定時間・非実行・白で復元 |
| 3   | タイトルを素早く連続入力     | 入力停止から少し後に 1 回保存される（デバウンス）              |
| 4   | 複数タイマーの並び順         | 保存順どおりに復元される                                       |

## BB-09 破損耐性

| #   | 手順                            | 期待結果                              |
| --- | ------------------------------- | ------------------------------------- |
| 1   | `timer.json` を壊した状態で起動 | 起動でき、空タイマー 1 つが表示される |
| 2   | 破損後の保存ディレクトリ        | `timer.corrupt-*` が退避されている    |

## BB-10 ウィンドウ・レイアウト

| #   | 手順                               | 期待結果                                                                     |
| --- | ---------------------------------- | ---------------------------------------------------------------------------- |
| 1   | ウィンドウをリサイズ               | UI 全体がサイズに連動して縮小・拡大                                          |
| 2   | 最小サイズまで縮小                 | 120x100 まで縮み、破綻しない                                                 |
| 3   | 背景をドラッグ                     | ウィンドウが移動する                                                         |
| 4   | ボタン・入力欄・時刻をドラッグ     | ウィンドウは移動せず、各操作が働く                                           |
| 5   | ウィンドウを閉じて Dock から再表示 | アプリは終了せず、保存データから復元される（実行中だったタイマーは失われる） |

## BB-11 通知許可

| #   | 手順                           | 期待結果                                     |
| --- | ------------------------------ | -------------------------------------------- |
| 1   | 初回起動                       | 通知許可が要求される                         |
| 2   | 通知を不許可にしてタイマー終了 | アプリは正常動作し、音は鳴る（通知は出ない） |
| 3   | 通知を許可してタイマー終了     | macOS 通知が表示される                       |

## BB-12 並び替え

| #   | 手順                                                         | 期待結果                                                                 |
| --- | ------------------------------------------------------------ | ------------------------------------------------------------------------ |
| 1   | ドラッグハンドルにポインタを重ねる                           | カーソルが「開いた手」になる                                             |
| 2   | タイマー A,B,C で、A のハンドルを C の下までドラッグして離す | 並びが B,C,A になる。ドラッグ中は他カードが動いて挿入位置が空く          |
| 3   | 2 の後に再起動                                               | B,C,A の順で復元される                                                   |
| 4   | ハンドルを掴んで元の位置に戻して離す                         | 並び順は変わらない                                                       |
| 5   | ハンドルをドラッグ                                           | ウィンドウは移動しない                                                   |
| 6   | カード背景・タイトル入力欄・時刻表示からドラッグ             | 並び替えは始まらない（背景はウィンドウ移動、他は各操作が働く）           |
| 7   | 実行中のタイマーを並び替える                                 | 計時は止まらず、残り時間・ボタン活性・黄色表示が移動後も保たれる         |
| 8   | ドラッグ中にタイマーが終了する                               | チャイム音と通知が出て、ドラッグは継続できる                             |
| 9   | セグメント編集中に別カードのハンドルを押す                   | 編集中の入力が確定する                                                   |
| 10  | 12 個のタイマーでウィンドウを縮め、ハンドルを下端近くへ運ぶ  | 自動でスクロールし、画面外の位置へ移動できる。上端でも同様               |
| 11  | ドラッグ中にポインタをウィンドウ外へ出して離す               | ドラッグは継続し、カードは先頭〜末尾の範囲に収まり、離した位置で確定する |
| 12  | 並び替え後にタイマーを追加                                   | 新規タイマーは末尾に追加される                                           |
| 13  | タイマー 1 個でハンドルをドラッグ                            | 並び順は変わらず、表示も崩れない                                         |

## 非機能の確認

| #    | 項目   | 手順・基準                                                                                                                            |
| ---- | ------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| NF-1 | メモリ | アイドル常駐時のフットプリントを計測し、30MB 以下（[10-requirements/non-functional.md](../10-requirements/non-functional.md) NFR-01） |
| NF-2 | CPU    | タイマー実行中の CPU が実用上無視できる水準                                                                                           |
| NF-3 | 起動   | ダブルクリックから表示まで体感即時                                                                                                    |
