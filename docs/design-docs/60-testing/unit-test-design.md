# 単体テスト設計

## この文書で決めること

`MultiTimerCore` と永続化ロジックの単体・結合テストのケースを設計する。実装は Swift Testing または XCTest を用いる（[strategy.md](strategy.md)）。

各ケースは「入力 → 期待出力」で書く。テスト対象の仕様は各仕様書が正本であり、ここではケースを列挙する。

## 前提となる設計要求

- 時刻取得を注入可能にする（`() -> TimeInterval` 相当のクロックを外から与える）。tick テストは実時間を待たない。
- 保存先ディレクトリを注入可能にする（一時ディレクトリでテストする）。

| ---------- | ------------------------------------------- | --------------------------- |
| TC-Time-01 | 0ms → 時分秒                                | 0, 0, 0                     |
| TC-Time-02 | 1000ms → 時分秒                             | 0, 0, 1                     |
| TC-Time-03 | 500ms → 時分秒（ceil）                      | 0, 0, 1                     |
| TC-Time-04 | 1ms → 時分秒（ceil）                        | 0, 0, 1                     |
| TC-Time-05 | 3600_000ms                                  | 1, 0, 0                     |
| TC-Time-06 | 最大 `99:59:59` のミリ秒                    | 99, 59, 59                  |
| TC-Time-07 | 負値 → 時分秒                               | 0, 0, 0（0 で下限クランプ） |
| TC-Time-08 | 時分秒(1,2,3) → ミリ秒                      | 3_723_000                   |
| TC-Time-09 | 整形: 5 → 文字列                            | "05"                        |
| TC-Time-10 | 整形: 59 → 文字列                           | "59"                        |
| TC-Time-11 | ミリ秒 → 時分秒 → ミリ秒 の往復（秒境界値） | 元の値に一致                |

## TC-State タイマー状態遷移（`TimerModel`）

対象: start/stop/reset/clear/tick とボタン活性。仕様は [20-spec/timer-behavior.md](../20-spec/timer-behavior.md)。

### 遷移

| ID          | 前提                    | 操作                   | 期待                                            |
| ----------- | ----------------------- | ---------------------- | ----------------------------------------------- |
| TC-State-01 | 停止・残り 0            | Start                  | 変化なし（Start 無効）                          |
| TC-State-02 | 停止・残り>0            | Start                  | 実行中、黄色 false                              |
| TC-State-03 | 実行中                  | Stop                   | 停止、残り保持                                  |
| TC-State-04 | 実行中                  | Reset                  | 停止、残り=設定、黄色 false のまま              |
| TC-State-05 | 停止・途中（残り≠設定） | Reset                  | 残り=設定                                       |
| TC-State-06 | 任意                    | Clear                  | 停止、残り=0、設定=0、黄色 false                |
| TC-State-07 | 実行中・残り>0          | tick で 0 到達         | 停止、残り=設定、黄色 true、終了処理が 1 回発火 |
| TC-State-08 | 黄色・停止              | Start → tick で 0 到達 | いったん黄色 false、到達後に再び true           |

### tick の計時（時刻注入）

| ID          | 前提                | 操作                       | 期待                                         |
| ----------- | ------------------- | -------------------------- | -------------------------------------------- |
| TC-State-09 | 残り 1000ms・実行中 | 300ms 経過を注入して tick  | 残り 700ms                                   |
| TC-State-10 | 残り 1000ms・実行中 | 1500ms 経過を注入して tick | 残り 0、黄色 true、終了処理 1 回             |
| TC-State-11 | 残り 1000ms・実行中 | 200ms を複数回に分けて注入 | 合計経過ぶんだけ減少（更新頻度に依存しない） |

### ボタン活性

| ID          | 状態                            | 期待（活性/非活性）                                 |
| ----------- | ------------------------------- | --------------------------------------------------- |
| TC-State-12 | 停止・残り 0                    | Start=非活性、Stop=非活性、Reset=非活性、Clear=活性 |
| TC-State-13 | 停止・残り>0・残り=設定         | Start=活性、Stop=非活性、Reset=非活性、Clear=活性   |
| TC-State-14 | 停止・途中（残り≠設定、設定>0） | Reset=活性                                          |
| TC-State-15 | 実行中                          | Start=非活性、Stop=活性、Reset=活性                 |
| TC-State-16 | 自然終了直後（残り=設定、黄色） | Reset=非活性                                        |

## TC-Norm 正規化・パース・補正（`TimerNormalization`）

対象: 保存データの正規化とパース。仕様は [30-data/persistence.md](../30-data/persistence.md)。

### 正規化

| ID         | 入力                             | 期待                       |
| ---------- | -------------------------------- | -------------------------- |
| TC-Norm-01 | 正常な 1 件                      | そのまま                   |
| TC-Norm-02 | `id` が空                        | 新規 UUID を採番           |
| TC-Norm-03 | `title` が 60 文字               | 先頭 50 文字に切り詰め     |
| TC-Norm-04 | `title` が数値型                 | 空文字                     |
| TC-Norm-05 | `configuredMs` が負              | 0                          |
| TC-Norm-06 | `configuredMs` が最大超過        | 最大 `99:59:59` にクランプ |

| TC-Norm-08 | `configuredMs` が非数（NaN/Inf） | 0                          |

### パース・補正

| TC-Norm-12 | `{ timers: [13件] }`                       | 先頭 12 件、補正あり     |
| TC-Norm-13 | `id` 無し要素を含む                        | 採番して補正ありフラグ   |
| TC-Norm-14 | 単一オブジェクト `{ title, configuredMs }` | 1 件配列に整形、補正あり |

## TC-Persist 永続化 I/O（結合、一時ディレクトリ）

対象: 保存・読み込み・削除・破損・直列化。仕様は [30-data/persistence.md](../30-data/persistence.md)。

| ID            | 手順                     | 期待                                            |

| TC-Persist-03 | 新規 `id` を保存         | 末尾に追加される                                |

| TC-Persist-07 | 壊れた JSON を読み込み   | 空配列・破損ファイルが `timer.corrupt-*` に退避 |

| TC-Persist-09 | 並行して多数の保存を発行 | 直列化され、ファイルが壊れない・最終状態が一貫  |
