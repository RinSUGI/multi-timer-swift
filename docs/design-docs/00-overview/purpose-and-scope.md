# 目的・対象範囲

## この文書で決めること

本プロジェクトの目的、対象範囲（やること・やらないこと）、および設計書全体で用いる用語を定義する。

## 目的

- macOS 上で、複数のカウントダウンタイマーを並列に扱える軽量なネイティブアプリを提供する。
- 常駐時のメモリ消費を小さく保ち、ダブルクリック起動から即使えるツールとして仕上げる（非機能要件は [10-requirements/non-functional.md](../10-requirements/non-functional.md) を参照）。
- 純粋ロジックを単体テスト可能な形に分離し、リグレッションを検出できる状態を維持する。

## 対象範囲（やること）

- 機能一覧は [10-requirements/functional.md](../10-requirements/functional.md) を参照。
- 振る舞いはブラックボックス仕様として明文化する（[20-spec/](../20-spec/) 配下）。
- Core（純粋ロジック）を単体テストで固め、UI・OS 機能を含むシナリオはブラックボックステストで確認する（[60-testing/](../60-testing/) 配下）。
- macOS アプリとしてビルド・配布できる状態を維持する（[70-packaging/](../70-packaging/) を参照）。

## 対象外（やらないこと）

- Windows / Linux 対応。macOS 専用とする。
- クラウド同期・アカウント・ネットワーク通信。通信ゼロ・テレメトリ無しを維持する。
- 自動アップデート機構。バージョンをファイル名で管理する配布モデルとする。
- Apple Developer ID による署名・公証（notarization）の必須化。実現できれば望ましいが、本プロジェクトの完了条件には含めない（[70-packaging/](../70-packaging/build-and-distribution.md) を参照）。

## 用語集

| 用語                       | 定義                                                                               |
| -------------------------- | ---------------------------------------------------------------------------------- |
| タイマー / タイマーカード  | 1 つのカウントダウン単位。タイトル・時刻表示・操作ボタンを持ち、独立して動作する。 |
| セグメント                 | 時刻表示 `HH:MM:SS` の「時」「分」「秒」それぞれの 2 桁部分。                      |
| 設定時間（`configuredMs`） | ユーザーが設定した基準時間。ミリ秒。リセット時の戻り先。永続化対象。               |
| 残り時間（`remainingMs`）  | 現在のカウントダウン残量。ミリ秒。永続化しない（起動時は設定時間に一致）。         |
| 自動リセット               | カウントダウンが 0 に到達し、通知後に設定時間へ自動的に戻る動作。                  |
| 時間切れ表示（黄色表示）   | 自動リセット後、数字を黄色で表示する状態。セッション内のみ保持。                   |
| 敷居線                     | 最下部のタイマー追加パーツにある区切り線。                                         |
| ドラッグハンドル           | タイトル行左端の三本線アイコン。並び替えのドラッグを開始する唯一の領域。           |
| DB / ストレージ            | タイマーを保存する JSON ファイル（`timer.json`）。                                 |
