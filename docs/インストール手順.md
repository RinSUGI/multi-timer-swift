# Multi Timer インストール手順

複数のカウントダウンタイマーを同時に使える macOS 用アプリです。以下の手順でインストールしてください（所要 2〜3 分）。

## 1. ダウンロード

配布担当者から共有された **`Multi Timer-1.0.6-universal.dmg`** をダウンロードします。

受け取った DMG ファイルの SHA-256 チェックサムが配布時に添付された値と一致することを確認してください。

```bash
shasum -a 256 "Multi Timer-1.0.6-universal.dmg"
```

## 2. インストール（Applications フォルダへ）

1. ダウンロードした **DMG ファイルをダブルクリック**して開きます。
2. 開いたウィンドウで、**Multi Timer アイコン**を右側の **Applications フォルダ**にドラッグ＆ドロップします。
3. これでインストール完了です。DMG のウィンドウは閉じて構いません。

## 3. 初回起動（ここが重要）

このアプリは Apple の有料証明書で署名していないため、**初回だけ** macOS の警告が出ます。ウイルスではありません。次の手順で一度だけ許可すれば、以降は普通にダブルクリックで起動できます。

1. Launchpad または Applications フォルダの **Multi Timer** をダブルクリックします。
2. 「"Multi Timer" は開発元を確認できないため開けません」と出たら、**「OK」** を押して閉じます。
3. **アップルメニュー → システム設定 → プライバシーとセキュリティ** を開きます。
4. 画面を下にスクロールすると **「"Multi Timer" は開発元を確認できないため…」** という項目があります。その右の **「このまま開く」** をクリックします。
5. パスワードまたは Touch ID を求められたら認証します。
6. もう一度確認ダイアログが出たら **「開く」** を選びます。

これでアプリが起動します。**2 回目以降は、ダブルクリックするだけで起動します。**

---

### うまくいかないとき

- **「このまま開く」ボタンが見当たらない**：先に手順 1〜2（一度ダブルクリックして警告を出す）を行ってから、システム設定を開いてください。ボタンは警告を出した直後に表示されます。
- **ターミナルが使える方向けの近道**：以下をターミナルに貼り付けて実行すると、警告なしで起動できるようになります。

  ```bash
  xattr -dr com.apple.quarantine "/Applications/Multi Timer.app"
  ```

## 4. 通知を有効にする

タイマー終了時に通知を受け取るには、macOS の通知許可が必要です。アプリを起動すると自動的に許可を求めるダイアログが表示されます。

許可を見逃した場合は、**システム設定 → 通知 → Multi Timer** を開き、通知を「オン」に設定してください。

---

困ったときは開発担当まで連絡してください。
